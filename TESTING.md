# Проверка первой версии

Проверки выполнены 23 октября 2026 года в подключённой Linux-среде.

## Автоматические проверки

- `npm test`: **14 тестов прошли**, ошибок и пропусков нет. Проверены словарь, весь каталог, намеренно испорченные сетки, детерминированная генерация для трёх уровней, ввод, замена, удаление, общие буквы пересечений, подсказки, сохранение, восстановление и ошибки localStorage.
- Все девять сеток полностью заполнены правильными ответами через независимый игровой движок. Состояние завершения определяется для каждой сетки, а удаление буквы снимает завершение.
- `npm run validate`: **9 из 9 сеток прошли** проверку словаря, длин, границ, стрелок, пересечений, связанности и полноты буквенных рядов.
- `git diff --check` и синтаксическая проверка изменённых JavaScript-модулей: без ошибок.

## Проверка в Chromium с Playwright

Выполнен `tests/browser-smoke.cjs`: **15 групп проверок прошли**.

- Главная страница, все уровни и фильтрация по завершению.
- Пустые ответы при первом запуске, определения непосредственно в клетках, SVG-стрелки.
- Русская экранная клавиатура и события физической клавиатуры через Chromium DevTools Protocol.
- Удаление и исправление, проверка ошибок, подсказки, сохранение и перезагрузка.
- Смена слова на пересечении, правила игры и пауза.
- Отмена сброса и полный сброс, прохождение до победного диалога, повторное открытие завершённой игры, статистика каталога.
- Генерация сложной сетки в Web Worker, сохранение нового сканворда и продолжение игры из каталога.
- Корректное сообщение для неизвестного ID.
- Размеры **320×568, 375×667, 390×844, 430×932 и 844×390**: отсутствие горизонтального выхода страницы, видимая клавиатура, доступное поле, ввод касанием, увеличение и обзор большой сетки по ширине.
- Загрузка главной и игровой страницы с префиксом подпапки репозитория, как на GitHub Pages. Префикс моделировался маршрутизацией Playwright к локальному статическому серверу.
- Во время сценариев ошибок JavaScript и сообщений об ошибках в консоли не было.

Отдельные скриптовые проверки в Chromium подтвердили перетаскивание поля мышью (прокрутка изменилась с 0 до 130 px) и масштабирование двумя касаниями (клетка увеличилась с 54 до 100 px). Визуально просмотрены снимки главной на компьютере и телефоне и игрового экрана телефона. Проверены определения всех девяти сеток при размере клетки 54 px: текст не пересекает зарезервированную область стрелки.

## Практические ограничения

- **Физический iPhone и Safari не проверялись.** WebKit в среде не установлен. Эмуляция мобильных размеров в Chromium подтверждает вёрстку и сценарии, но не является проверкой Safari.
- Публикация GitHub Pages не проверялась на новой версии: изменения подготовлены в отдельной ветке для слияния. Статический сайт не требует сборки и готов к размещению из корня ветки.
- Словарь небольшой и авторский. Вопросы отредактированы вручную; автоматическая проверка доказывает структурную корректность сеток, но не уникальность всех возможных языковых ответов.
- Алгоритм использует ограниченный жадный поиск, а не оптимальную упаковку всех клеток. Некоторые клетки остаются блоками. При неудачной генерации сайт сообщает об этом и сохраняет доступ к готовым сеткам.
- Сохранения локальны для текущего браузера. Очистка данных сайта удаляет прогресс. Вход, серверная база и синхронизация между устройствами не входят в первую версию.
