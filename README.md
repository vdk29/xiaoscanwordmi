# Ксяосканвордми

Мобильный сайт с классическими сканвордами в светлой пастельной стилистике.

## Файлы
- `index.html` — структура сайта и экран игры.
- `style.css` — адаптивный дизайн для телефона и компьютера.
- `data.js` — коллекция сканвордов и собственные короткие определения.
- `app.js` — сборка сеток, выбор вопросов, ввод букв, подсказки и локальное сохранение прогресса.

## Запуск через GitHub Pages
1. Открой **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выбери **Deploy from a branch**.
3. Укажи ветку **main** и папку **/(root)**, затем нажми **Save**.
4. Подожди, пока GitHub опубликует сайт. Адрес будет показан в этом же разделе.

Сайт работает без сервера и платных API. Прогресс сохраняется в локальном хранилище браузера на устройстве.

## Текущий этап
Первая рабочая версия: каталог, фильтры сложности, алгоритмическая сборка пересекающихся слов, ввод букв с физической клавиатуры, подсказка-буква, проверка и сохранение прогресса. Сетка собирается из собственной базы определений; перед публичным запуском стоит отдельно протестировать каждую сгенерированную сетку и улучшить редакционную проверку вопросов.
